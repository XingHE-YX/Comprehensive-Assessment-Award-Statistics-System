# 名单、回收站与学年删除验收

日期：2026-09-10。用户范围为单班级；名单必须先于学年创建，旧 26–27 本地测试学年清理并重建，25–26 待激活学年保留。

## 行为

- 在学年设置下载 Excel 模板，导入姓名＋文本学号。支持 XLSX、UTF-8 CSV 和制表符粘贴；先校验名单，再填写学年信息。模板不包含会意外导入的示例学生。
- 新学年未激活；激活前必须有名单。已有学年通过“管理名单”追加学生，原名单保留。表内或与原名单冲突的姓名使整批导入失败；同名同学号去重。
- 成果、无材料声明及学生修改均校验所属学年的姓名和学号。新申报仍遵守当前学年与截止时间，补录不延期。
- 所有审核状态及声明都可单条/批量删除，确认后进入回收站；列表、分值、导出和学生访问排除已删除记录。恢复保留原审核信息及附件。同一声明已经重新提交时，恢复冲突且整批回滚。
- 删除整个学年永久清理其名单、全部记录和附件（包括回收站）。页面显示依赖计数，要求输入完整学年名称并勾选确认。删除当前学年关闭申报，可随后创建同名学年；其他学年与系统设置保留。
