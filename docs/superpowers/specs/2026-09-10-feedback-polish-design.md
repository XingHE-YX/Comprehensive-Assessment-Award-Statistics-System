# 本地测试反馈：列表、修改码与极简界面

依据用户 2026-09-10 最新要求：美化但保持极简；无材料声明进入管理员列表并标为“无申报材料”；管理员能够查询修改码；证书选项 CET-6 改成 CET-4/CET-6。继续采用现有 Rust/Axum/Askama/CSS 架构。

## 行为

- 管理员同一列表展示成果和无材料声明，按提交时间倒序。声明行显示真实姓名/学号和时间，明确标记“无申报材料”，无成果编号、分值或审核链接。重复声明沿用既有 upsert；后来提交成果不删除原声明。声明的筛选继续只使用学年/姓名/学号，与现有统计和 Excel 规则一致，界面明确说明。
- 修改码仍用 Argon2id 验证，新增认证加密密文供管理员查看。使用现有 tower-sessions/cookie 的 PrivateJar 加密能力，避免自制密码算法或新依赖；密文按申报编号绑定认证上下文，密钥来自持久配置 SESSION_SECRET。该密钥必须随数据备份、保持稳定，轮换需要迁移密文。修改码不会出现在学生详情、普通列表、Excel、日志或 URL 中。
- 旧记录只有哈希，不能还原原码。管理员详情给出真实说明和手动生成新码的 POST/CSRF/确认操作，绝不在 migration、页面读取或升级时自动重置。重置原子更新哈希、密文和凭据版本；旧修改码和旧学生验证会话失效，记录状态、审核备注、分值和附件不变。管理员操作后看到新码；坏密文/错误密钥不泄漏内部错误。
- 证书新选项与成绩标签显示 CET-4/CET-6；新值为 `CET-4/CET-6`。兼容已有 `CET-6` 数据和 `cet6_score` 存储字段，旧记录能正常显示、编辑与导出，新值对应成绩仍是 Excel 数值单元格。
- 同步收尾既有表单缺口：无 JS 无材料声明要有可用回退；非校级荣誉不要求填写校级类别，校级类别可选并提供原始需求的六项选择（含“其他校级荣誉”），旧文本可继续显示/编辑。首页截止时间标明 UTC。

## 视觉

采用清爽蓝白界面：保留既有色板、16px 中文系统字体、4px 间距刻度、8px 圆角、720/1280px 内容宽度和 640/1024px 断点。用细边框、白色表单区域、整齐的分组标题、统一字段间距和按钮尺寸改善层级。声明/成果选择做清晰的原生单选块，管理员统计、筛选、列表各自成组，状态同时使用文字与颜色。

不增加海报、渐变、图表、远程字体/图标、框架或构建链。避免嵌套卡片、!important 和 6px 等非标间距。所有关键表单保留无 JS 操作路径；移动端按钮堆叠、表格可滚动。管理员查看/重置修改码的说明只表达用户需要理解的效果。

## 实施与交付

三项可独立评审的变更：声明列表；管理员修改码；学生表单/CET/视觉。使用有意义的失败测试后实现，逐项检查并最终全量验证。以 320×568、390×844、768×1024、1440×900 实际浏览器检查页面与流程。

旧约定“修改码只保存哈希且只在成功页明文显示”与新要求冲突，由用户最新要求覆盖；同步更新 PRD、APP_FLOW、BACKEND_STRUCTURE、AGENT 的相应条目。当前运行的本地预览保留到新版本验证完成；升级前备份数据库与附件，保持原配置/数据卷和 localhost、Wi-Fi 入口。旧数据的修改码不可恢复这一限制必须在交付说明中明确。
